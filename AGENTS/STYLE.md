# STYLE.md

## Design Concept
Name: The Curious Oddity
Personality: curious, surreal, experimental, self-aware.
Balance: 30% professional, 70% experimental.

The website should feel like an independent digital publication,
not a generic developer portfolio.

## Brand
Name: Hilman Apriadi
Primary tagline: "Not just a developer, but a curious human."
Supporting copy: "I build digital products, explore AI,
and document the journey."

Do not portray the owner as an expert in every listed technology.
Use honest descriptions based on verified experience.

## Color Tokens
- Paper Cream: #F7F3EA
- Void Black: #171717
- Acid Lime: #C6FF00
- Dream Blue: #A9D2D8

Use cream and black as primary colors.
Use lime sparingly for CTAs, highlights, and interaction states.
Use blue mainly for surreal artwork and selected visual sections.

## Typography
- Headings: Space Grotesk
- Body: Inter
- Technical labels: JetBrains Mono

Use expressive headlines, readable body text, and small
monospaced labels for metadata and playful annotations.

## Art Direction
- Surreal objects and impossible landscapes.
- Oversized editorial typography.
- Asymmetric compositions and generous whitespace.
- Occasional handwritten notes, visual annotations, and absurd humor.
- Prefer a few memorable visual elements over constant decoration.

Avoid generic SaaS layouts, excessive gradients, excessive glassmorphism,
and repetitive rounded cards.

## Layout
- Desktop: expressive two-column hero and multi-column project grid.
- Tablet: simplified composition with balanced text and imagery.
- Mobile: stacked content, readable typography, single-column projects.
- Never allow decorative artwork to obscure essential content.

## Motion
- Subtle parallax and slow floating objects.
- Clear hover and focus states.
- Custom cursor effects only on suitable desktop pointers.
- Respect prefers-reduced-motion.
- No essential content may depend on animation.

## Content and UX
- The full name must remain clearly visible.
- Projects must explain purpose, contribution, and verified results.
- Navigation must remain obvious despite experimental visuals.
- Every interaction must provide a clear, useful outcome.
- Prioritize accessibility, performance, and readability over spectacle.

## Responsive Rule
Design mobile intentionally; do not merely shrink the desktop layout.
